# Getting Started with ROS2 (Linux/WSL)

Our target platforms for these guides are:

* Bitcraze CrazyFlie 2
* iRobot Create 3
* iRobot Create 2 (with a Raspberry Pi)
* iRobot root

We need to pick a ROS release that works for all those.  We'll aim for Kilted Kaiju, however that may change.

I will be testing this out on EndeavorOS (Arch-based), popOS! (Debian-based), and WSL2.  If you use a different distribution then you'll need to follow a [ROS installation guide for your platform](https://docs.ros.org/en/kilted/Installation.html).

## Using Docker

I'm personally not huge fan of Docker and have no desire to start.  If you are interested in going that route here is the [ROS guide](https://docs.ros.org/en/kilted/How-To-Guides/Run-2-nodes-in-single-or-separate-docker-containers.html).
