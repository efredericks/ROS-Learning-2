# First Simulations

Our goal for this module is to get some basic simulations up and running, including defining the environment, instantiating robots, and deploying a basic controller to have that robot navigate from one waypoint to another.  We will do both the iRobot Create3 and bitcraze Crazyflie 2.1.  

> The general premise for these guides now will be to first **recreate** the tutorial, **extend** the tutorial (answers available), and then complete the **homework** for the tutorial (answers not available).

Our goal is to have each of our robots navigate to a set of waypoints and indicate success or failure at the end of the time limit.  This will involve (1) setting a waypoint in space for both and (2) developing and executing a basic controller for each robot.

For now we aren't going to worry about the environment at all or any form of obstacle avoidance, we simply want to trigger the motors to move.

## Environment

One thing to consider is that we are in 3D space, even though the Create only really moves in a 2D space.  All of our transforms and poses will have an `[x, y, z]` component.  For the Create we won't care as much about the *z-axis*, but it is there and is needed for our setup.

We also will make our first ROS package (one for each environment).  The idea will be that you build out the package per mission objective, and that they can be duplicated throughout as a blueprint.

Last bit, there are some differences between the documentation and the current version of ROS.  Unfortunately this is a common thing - we get to experience the joys of *debugging obsolete documentation*.
